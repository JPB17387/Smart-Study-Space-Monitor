# Release Notes — Smart Study AI Platform

## Version
v2.0.0

## Release Summary
This release marks the transition from the earlier OLED-based prototype to a browser-based Arduino Uno Q experience. The project now uses the Arduino App Lab WebUI and Bridge RPC layer to present live study telemetry and control the device from a web dashboard.

## What Changed in This Release

### New WebUI Architecture
- Introduced a browser-based dashboard for the Arduino Uno Q.
- Added a WebUI front end under the `assets/` directory.
- Added Linux-side App Lab integration through `python/main.py` and `python/device.py`.
- Implemented Bridge RPC communication between the MCU and the host-side application.

### MCU Integration
- The Uno Q sketch now exposes telemetry and control RPCs through `sketch/communication.cpp`.
- The MCU reports motion, light, focus state, session time, idle time, and recommendation text.
- Session commands such as start, pause, resume, stop, and break are forwarded through the WebUI.

### Dashboard Features
- Live telemetry cards for motion, light, session time, and idle time.
- Recommendation display and session-state badge.
- Buttons to start/pause/resume/stop sessions and begin a break.

### Hardware and Firmware Scope
- PIR sensing remains the primary motion input.
- LDR sensing remains the light input.
- Buzzer feedback is retained for session actions.
- The older SSD1306 OLED UI path is no longer the primary release experience.

## Migration Note
The v1.0.0 implementation used an SSD1306 OLED display and local button-driven UI. The v2.0.0 release replaces that experience with a WebUI experience designed for the Arduino Uno Q platform.

## Current Status
- Implemented: Uno Q WebUI dashboard, RPC telemetry, session controls, motion/light sensing, recommendation delivery.
- Partially represented: the project still contains legacy OLED-related source files from earlier work, but the current release path is the WebUI-based flow.
- Not fully validated in this environment: hardware execution and live device testing were not performed here.
